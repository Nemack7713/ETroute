**Documentation status: Planned contracts plus linked implementation evidence.**

ETuMAX owns the Android interface and session control. ETroute owns native launch supervision. The target production path uses a verified Python runtime and absolute executable paths, without Chaquopy or an unverified fallback.

This site is an engineering guide, not proof of runtime admission. Diagrams explain contracts; the interactive admission component only simulates decisions.

## Evidence labels

| Label | Required meaning |
| --- | --- |
| Planned | Implementation or acceptance is incomplete. |
| Implemented | Source exists at the cited revision; this does not imply successful execution. |
| Host-verified | Named checks passed on a host at the cited revision. |
| Device-verified | Named checks passed on an identified Android device and build. |

Use labels per capability, not as one global badge. An APK build is not a passing device test. A native smoke test is not evidence that Python started.
